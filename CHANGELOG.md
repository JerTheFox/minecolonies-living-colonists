# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- In-game settings screen with every option of the config file on four tabs (Connection, Behaviour, Limits, Usage): values are checked before saving and apply at once; buttons test the chat and character models and load the provider's model list. Opens from the mod list's *Config* button and an unbound *Living Colonists settings* key. In a world it edits the server's settings (operators and the single-player owner change, others look); from the main menu, the local file. API keys are never sent to players, only whether they are set.
- Translated names and tooltips for every config option, so Configured and NeoForge's config screen show them properly.
- Promises have a worth, from a trifle (a bit of dirt: keeping it changes nothing) to something precious (a stack of diamonds: a big step); breaking one costs more the more it was worth. A kept promise warms a colonist toward you at most once a day, and while you still owe a spoken promise in the colony, colonists turn new ones down ("keep that one first"), so promises can't be farmed.
- Promises made in the colony chat to a named colonist ("Idris, I'll bring you diamonds in ten minutes") are written down too, and closed when the chat shows they were kept.
- "I will work on it!" in a colonist's plain dialogs is a promise as well: a hospital or a cure, a workplace upgrade, a warehouse, a guard tower near home or work (closed by themselves when it happens), better or more varied food. Dialogs with nothing to promise, like a full chest or the rain, are skipped.
- "I will work on it!" in a colonist's request dialog (a builder asking for a pickaxe) is a promise due in one Minecraft day: kept when the request is delivered, by anyone; dropped without blame if the colony cancels it; cancelling it yourself counts as breaking it only once it is overdue. A small read-only mixin into MineColonies' citizen data notes the button, since MineColonies sends no event for it.
- Colonists talk like ordinary people rather than eager helpers: short lines, no forced cheer, praise or a question at the end of every line; each colonist has a mood for the day (calm, tired, irritable, distracted, bored, gloomy or in a good mood), worse moods more often when they are unhappy.
- Newborns stay out of conversations for a day unless named, and children talk like children.
- `/lcdebug relations [name|all]` shows how colonists get along with each other.
- The reply language is decided by code: the alphabet of the player's message (names don't count), with the game locale saying which language of that alphabet, so an English question gets an English answer even when the colonist's notes are in Russian. Short messages ("ok") keep the language of the talk; a Latin-alphabet language other than English is still left to the model.
- The colony chat finds whom a message addresses by code before asking the model: names in any grammatical case ("Джону" finds Джон), Latin names written in Cyrillic and back ("Адаир" finds Adair), a surname nobody else has, several names at once, and professions in the words of the game's own translations plus everyday ones ("строители", "guards", "повар"). Messages plainly for everyone ("всем привет") skip the routing request too. Fewer requests and about a second faster.
- Errands, the groundwork: colonists look things up and take orders through code. Only the colony's owner and officers give orders (a friend is turned down in character), only in their own recent words (the model has to quote them), and nothing happens until the player says yes, by a *Yes* / *No* button in chat or a short "yes" / "no"; each player answers only their own order, and an order waits a minute. `/lc undo` takes the last order back; `/lcdebug orders` shows what was ordered.
- `check_stock`: how much of an item the warehouses hold. The item is found by code among the game's names and translations, with plural and case forms; when several items fit ("planks"), the colonist asks which one. Ported from Colonist Errands.
- `upgrade_building`: a colonist orders a building's next level from the builders, like the building's own window does; the building is found by code by its name in English, Russian or the player's language, or its custom name, and undo cancels the work order.
- The rest of the first batch of errands. Look-ups: `guard_gear` (which guards lack armour, a weapon or a shield) and `fallen_colonists` (who died and how, from the colony's records). Orders: `arm_guards` (requests every missing piece of guard gear; undo cancels the requests), `farmer_plant` (a farmer sets a field to a crop, an empty one first; undo puts the old crop back), `start_research` (as the university's window does, the cost can't be given back), `add_to_menu` (a dish on the restaurant's menu; undo takes it off), `sort_warehouse`, `move_home` (a colonist moves into a home with a free bed; undo moves them back). `notify_when`: a colonist tells the player once they get an item while working, for about an hour. `arm_guards`, `farmer_plant` and `notify_when` are ported from Colonist Errands.
- The MINIMAL profile runs the colony by chat: colonists answer plainly and briefly, without character, mood, small talk or memory, and still look things up and take orders ("upgrade the university" → yes / no). Look-ups and orders now work at any perception level but off.
- Colonists write to a player first, privately: any colonist of the colony, taking turns: whoever hasn't spoken up for long (or ever) comes first, whoever just did steps back, the talkative only a little more often, so quiet and content colonists get their say too; while the player is inside it and has been quiet for a minute and a half, with no colony conversation going on, no order waiting for a yes and no raid, at uneven times drawn by the dice (sometimes a long silence), never right at login. What about is the dice's choice, from the colonist's real problems first (no home, hunger, illness without care, something only a player can bring, building materials, unhappiness), then following up something the player told them, news, or small talk on a topic not had with that player for hours. A problem raised again and again without a fix is put more sharply, until the colonist says they won't ask any more; once solved, it starts from scratch. A colonist who complained lately leans to other topics; one who dislikes the player keeps to their problems; a friend chats more. How often is the new `initiative` level (profile: low about every half hour, default about every 12 minutes, high about every 6, never more than 1, 2 or 4 in 20–40 minutes), and each colonist writes first to the same player at most every 45 minutes (20 on high).
- The "talk to colonist" key and `/lc talk` reach a colonist up to 16 blocks away (was 8) when you look at nobody. What was raised is kept with the world. Asleep colonists don't write, a colonist says "haven't talked for a while" only when it's true, and without a model or tokens left the colony just stays quiet.
- Livelier colony chat: when a colonist changes the subject, code picks the new topic from a long list of broad ones (work, neighbours, family, memories, plans, food, animals, stories, worries and more), not one the talk already had, instead of the model falling back on the weather; code also picks the shape of a line now and then (a quick reaction, a question, a little story) and keeps colony lines to two sentences. Topics change less often than before.
- Each colonist has a way of talking for life (brief, chatty, proverbs, bookish, grumbling, dry jokes, shy, blunt and more), picked by code from their name.
- A colonist remembers what they did on a player's order ("on Alex's order I sorted the warehouse") as a fact.
- Familiar forms of a player's name come only from colonists who like them; one who dislikes the player doesn't use the name at all.
- Moods colour how colonists talk instead of being said aloud in every line; rude, crude or hateful requests are brushed off in character.
- The routing request (whom a colony message is for) asks DeepSeek to answer without thinking first, about twice as fast with the same picks; replies keep thinking, since without it colonists made up facts. Other providers get no such field.
- Colonists of one colony are offered the same functions, so the provider's prompt cache works across them; whether this colonist may do it is checked when it's called.
- Walking on the player's word (owners and officers, at once, without a yes): `come_here`, `follow_me`, `wait_here`, `go_to` a building, `call_colonist` over, `gather` everyone or one profession here or at a building, `everyone_home`, `lead_me` to a building or a colonist, and `stop_walking` (one colonist or everyone the player sent off). While on a walk the colonist's own routine is paused through MineColonies' public state machine, no mixin; each walk ends by itself after a few minutes. Ported from Colonist Errands.
- Couriers: `fetch_item` (a courier brings the player something from the warehouse) and `deliver_item` (from the warehouse to a building), confirmed by the player; jobs wait on a board for a free courier, `courier_board` shows it, and undo takes a job off before it is picked up. Ported from Colonist Errands.
- Guards: `guard_me` (escort the player), `defend_here` (come and hold the player's spot), `red_alert` (everyone to their tower), `patrol_here` (the player's spot on a tower's patrol route), `stand_down`, and `guard_leaderboard` from a tally of the guards' kills kept with the world. The towers' own settings come back on stand down, undo, after twenty minutes, when the player leaves, and before the world is saved on shutdown; only options a tower offers are ever set. Ported from Colonist Errands.
- Walks end when the colony is raided, so colonists can flee and guards fight; guards stay at their posts when everyone is sent home, and hold or patrol spots inside the colony only. A courier who can't reach the player never loses what they carry, and a job whose courier gave up doesn't hang on the board. A player who lost their rank can't confirm an order asked for before. Stale *Yes* / *No* buttons aren't shown. A passed-on message is never taken as instructions by the colonist, and falls back to a plain notice if the colonist gives no line. Item names are prepared in the background at server start instead of on the first look-up.
- Colonists are offered only the functions that fit: guard orders where there are towers, courier jobs with a courier, research with a university, a farmer's field to a farmer.
- Mail and reminders: "tell Alex the bread is ready" is kept by the colonist and passed on, in their own words, when Alex next comes to the colony (found among the colony's players by nickname or the names colonists use); "remind me in ten minutes to check the oven" comes as the colonist's private line at that time, wherever the player is. Both are saved with the world; a message waits up to a week of game days, a missed reminder up to a game day; five of each per player. Without a model, a plain notice delivers them.
- The *Yes* / *No* buttons for an order come right after the colonist's line asking for them, not before; every order a colonist turns down is written to the server log with the reason.
- A promise made with "I will work on it!" in a request dialog is worth what the requested thing is worth, by code from the item and the amount: rarity, the common tags (gems, ingots, ores, storage blocks), a tool's durability, enchantments; a stack of dirt is a trifle, a stack of diamond blocks something precious.
- More orders, each confirmed by the player and undone with `/lc undo`: `take_job` (the colonist asked takes a job or switches to one where a position is free, found by building or profession name in any of the game's languages; undo puts them back), `request_craft` (an item ordered from a crafter who knows the recipe, delivered to the postbox, the town hall or a named building; undo cancels the request), `prioritize` (a building's work order moved to the front of the builders' queue; undo restores its place). Ported from Colonist Errands.
- More look-ups: what the colony waits for from players (things nobody can make, requests nobody took on, materials the builders lack), who is unhappy and why, what is being built and by whom, how long the food in the warehouses lasts and who is hungry, which way and how far a colonist or a building is, and the research going on with what it unlocks (ported from Colonist Errands). Every look-up is written to the server log.
- A question to the whole colony goes to whoever looks after it: food to the cooks, the warehouse and deliveries to the couriers, buildings to the builders, research to the researchers, defence to the guards, health to the doctors, crops to the farmers; everyone else may join in after. What a colonist looked up stays in the conversation for the others, so nobody contradicts the colony's records.
- Asking for stock of something with many kinds ("wool") counts every kind and names only those in stock, instead of listing possible kinds as if they were there; British spellings ("grey wool") are understood.
- While a player talks with the colony, other colonists join in only now and then (about one line in three messages) and wait twelve seconds first, so the player can answer; a new message from the player cancels them. After a look-up or an order the chat mostly stays quiet. Colonists talk at length among themselves only once the player has been silent for a minute.
- A follow-up in the colony chat for nobody in particular ("and the lime one?") goes to whoever answered the last question; a player's message is never left unanswered: if the colonist asked has nothing to say, another answers. Colonists talking among themselves go one and a half times slower, so a player can get a word in.
- A colonist asking for a confirmation asks the player by name, and other colonists don't confirm for them.
- Colonists know the hour ("midday, about 12 o'clock") and keep the time and the weather as they are instead of making the sun set mid-talk; they never call anyone a player or mention the game; a character trait shows in how they talk rather than in every line, and a topic someone asks to drop is dropped.
- "Idris is typing..." while a colonist writes a line you will see, shown after a reading pause; the dots jump in a small wave now and then.
- Colonists' names are shown in their colony's color; the arrow and addressee of private lines too.
- Colony and private lines are written to the server log, like player chat.
- Colonists react to what happens in the colony: a death, a birth, a child growing up, a newcomer, a finished or upgraded building, the start and end of a raid open a colony conversation while players are around (at most once every five minutes per colony).
- A colonist reminds you in private of a promise past its deadline, once per promise.
- Colonists remember how they get along with each other, written down from colony conversations: friends and rivals answer each other more often, and colonists argue more with those they dislike.
- `colonyChatAnywhere` (off by default): colony members read and write their colony's chat from anywhere.
- Optional `[limits]`: `messagesPerPlayerPerHour` and `tokensPerDay`, both off by default.
- Prompt templates start with the rules shared by every colonist, so the provider's prompt cache covers them.
- Colony chat is a living conversation: whoever a message addresses answers first, then other colonists may join in, reply to each other or let the talk die down; talkative archetypes speak up more often, quiet ones rarely. How long threads run without players follows the new `conversation` level (up to about 16 lines on `high`). This replaces the two or three random answers.
- Promises: when you promise a colonist something in a private talk ("I'll bring you planks tomorrow", "you'll have a house in a week"), they write it down with its deadline. They remind you when it is overdue, thank you when it is kept and are disappointed when it is broken. Promises of a home, a job or treatment close by themselves when the colonist gets one, and promises of a building when it is finished; a promise left past its deadline for three days counts as broken, one without a deadline is forgotten after ten days. Adapted from Colonist Errands.
- Relations: colonists remember whether you are kind or rude to them and whether you keep your word, and it shows in their tone. When several colonists agree, the whole colony knows your reputation.
- `/lcdebug bonds show|clear [name]` lists a colonist's promises and relations, or forgets them.
- Replies follow the language of your last message even when the colonist's notes mention names in another script.
- Long memory: once a private talk or a colony conversation goes quiet, the character model writes down what the colonists who took part would remember (promises, plans, news, feelings), each fact with an importance. Facts go into their prompts and fade with age, important ones last longer; how many and how long follows the `memory` level (5 facts for up to 2 days on `low`, 15 for 7 on `default`, 60 for 30 on `high`). Facts of colonists who are gone are cleaned up once a game day.
- Gossip: now and then a colonist passes on something another player told them in private, as hearsay, in the colony chat or in your private talk; whoever hears it in the colony chat remembers it too. What a player asked to keep secret stays secret.
- `/lcdebug memory digest` writes down every conversation waiting to be noted right away; `memory show` lists the facts, `memory clear` forgets them too.
- Short memory: colonists remember their recent private talks with each player (how much and how long follows the `memory` level), and the colony chat keeps its recent lines.
- Lines come one after another with a reading pause and a typing time that grows with the length of the line.
- `/lcdebug memory show|clear [name]`, `/lcdebug thread` and `/lcdebug thread break` (stops a colony conversation) for operators.
- Private talks are marked in chat as `<Player> → <Colonist>` and back, the arrow and addressee in gold.
- The *Players | Colony* switch above the chat input shows only for players who belong to a colony (owner, officer or friend).
- The private talk and focus keys say what to do when nobody is in sight.
- Keys: **T** chats with players (and leaves colony mode or a private talk), **Y** writes to the colony, **U** talks to the colonist you look at privately; the mode switch key is unbound by default.
- In colony conversations the mod picks how each colonist reacts: disagree (more often for contrary archetypes, set by the new `contrariness` field), agree with a twist, change the subject or ask someone a question, so threads don't collapse into everyone agreeing.
- Retries now also cover lost connections: 3 by default, 1, 3 and 8 seconds apart; the log names the full cause of a failure.
- Colonists can look up colony data while answering, through function calling: facts about another colonist, who fits a profession best by its primary and secondary skill, and an overview of the colony. `useTools` turns it off for providers without tool support. `/lcdebug prompt` shows the calls.
- Colonists describe skills, moods and amounts in words instead of quoting numbers, unless asked how many.
- `playerNames` in the config: what colonists call players instead of their nicknames, e.g. `"Steve42=Steven,Steve,Stevie"` (most common first). Colonists use the name only now and then, not in every reply.
- Builders know what they are building and which materials are still missing.
- Every worker knows their workplace level and the orders it is making for others (crafters, the warehouse, couriers); farmers know their fields, miners their mine levels, couriers their queue, healers the patients, researchers the research in progress.
- Colonists answer what they are asked instead of reciting their worries: only about a quarter of replies may mention one worry unasked, and only about a third may use the player's name (the mod decides per reply, since a model can't keep "now and then").
- Colonists tell apart deliveries that are on the way from things nobody in the colony can provide and a player has to bring.
- Perception: colonists know their job and which work they can't do (and which workplaces the colony has), their home, hunger and where to get food, health and sickness, happiness and its causes, what their workplace is waiting for, the weather, the colony and a raid, and how their family and coworkers are doing. How much they know follows the `perception` level. `/lcdebug colonist` shows it.
- Prompt files the player never edited follow the mod's newer defaults after an update; edited ones are kept.
- Personalities: every colonist gets an archetype, picked mostly from their MineColonies skills with a share of chance, and a short background written once by the character model. Children get a description of their temperament instead of a past, sometimes take after a parent, and get an adult background when they grow up.
- Archetypes (`config/livingcolonists/archetypes/*.json`) and prompts (`config/livingcolonists/prompts/*.txt`) are plain files: edit, add or delete them. Eleven archetypes come with the mod.
- `/lcdebug colonist`, `archetype <id|reroll>`, `bio regenerate`, `prompt` and `reload` for operators (and in single-player worlds with cheats on). Without a name they act on your conversation partner, or else on the colonist you look at.
- A "Focus on colonist" key (unbound by default) picks the colonist you look at as your conversation partner without opening the chat, handy for `/lcdebug`.
- Profiles `MINIMAL`, `LIGHT`, `DEFAULT`, `IMMERSIVE` set how deep personalities, perception and memory go; each module can be overridden separately. `/lcdebug profile` shows or changes the profile.
- Only a colony's owner, officers and friends can talk to its colonists (`membersOnly`, on by default).
- A short cooldown between one player's messages to colonists (`cooldownSeconds`, 3 by default).
- Separate `chatModel` and optional `characterModel` (for backgrounds and memory summaries; empty uses the chat model).
- Retries after temporary failures (timeouts, rate limits, server errors) and an optional fallback API, for example a local model.
- Token usage statistics per model, for this run and in total, saved with the world: `/lcdebug stats` (operators).
- Two chat modes, switched with **H** or with the *Players | Colony* switch above the chat input. In *Colony* mode, while you are inside the colony's borders, your ordinary chat goes to the whole colony: a colonist you name answers, a profession you name ("builders, when will you finish?") gets answers from those colonists, and otherwise two or three random colonists answer. The model works out who is addressed, in any language. Players inside the colony see the conversation.
- Private talks. **Y** ("Talk to colonist") picks the colonist you look at and opens the chat; your messages then go to that colonist only, like a direct message, from anywhere in the colony. The colonist keeps working. Press **Y** while looking at nobody, click the ✕ above the chat input, or leave the colony to end it. Clicking a colonist's name in chat starts a private talk too.
- Colonists answer even when they are in unloaded chunks of the colony.
- Colonists take a moment before answering, as if typing, and several answers in a colony come a couple of seconds apart.
- `apiKey` in the config, for players who don't want to deal with environment variables.
- `/lc lock` and `/lc mode [players|colony]` as fallbacks for clients without the mod.
- English and Russian translations.
- `/lc talk <message>`: talk to the colonist you look at, or the nearest one within 8 blocks. The reply comes from the language model and appears in chat like a player message; hovering the name shows the profession and colony.
- Project skeleton from the NeoForge 1.21.1 ModDevGradle MDK: mod id `livingcolonists`, `runClient` and `runServer` with MineColonies 1.1.1405 and its dependencies.
- Exact version pins for Minecraft 1.21.1, NeoForge 21.1.264 and MineColonies 1.1.1405.
- Mod logo in the mod list.
- Common config `livingcolonists-common.toml` for the OpenAI-compatible API: base URL, model, API key or its environment variable, timeout, max tokens, temperature and extra request parameters. Defaults point to DeepSeek (`deepseek-flash`).

### Fixed

- "Kept your promise" and "waited in vain" notices show above the hotbar, like "will remember your promise", instead of in chat.
- A reply prompt carries at most twenty of a colonist's facts, the most important ones, instead of all of them.
- Colony conversations no longer circle one joke for the whole day: a new conversation sees only a couple of lines from before it, and after a few lines colonists change the subject more often.
- Colony conversations leave fewer, more useful facts in memory: news, plans, decisions and promises, not banter.
- A reply cut off by the token limit no longer ends mid-word in chat: only its finished sentences go out, and replies get more room for the model's reasoning.
- A newcomer who got the id of a colonist who died or left no longer inherits their character, memories, promises and relations (MineColonies reuses ids); a deleted colony's data is dropped too.
- An archetype file with a value of the wrong type is skipped with a warning instead of failing the server start.
- Colonists no longer make up colony events, noises or visitors, which then spread as gossip.
- A colony conversation that ended while a reply was still on its way no longer comes back to life.
- Old conversations that are fully written down no longer pile up in the world's data.
